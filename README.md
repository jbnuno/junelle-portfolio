GESTALT PRINCIPLES:

PROXIMITY
I used the Gestalt principle of proximity on the Projects page by grouping related project information into individual project cards. The spacing between the cards separates each project, while the content inside each card is kept together to show that it belongs to the same project.

Similarity

I used the Gestalt principle of similarity throughout the website by keeping consistent typography, navigation styling, colors, borders, and button styles across all pages. This creates a consistent visual identity and helps users understand that all of the pages belong to the same portfolio website.
